# Fontes do App de Astrologia

Este diretório deve conter as seguintes fontes:

## Fontes Necessárias

### Outfit (para headings/títulos)
- `Outfit-Regular.ttf`
- `Outfit-Medium.ttf`
- `Outfit-SemiBold.ttf`
- `Outfit-Bold.ttf`

**Download:** [Google Fonts - Outfit](https://fonts.google.com/specimen/Outfit)

### Inter (para body/texto corrido)
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`
- `Inter-Bold.ttf`

**Download:** [Google Fonts - Inter](https://fonts.google.com/specimen/Inter)

### Playfair Display (para títulos místicos/especiais)
- `PlayfairDisplay-Regular.ttf`
- `PlayfairDisplay-Medium.ttf`
- `PlayfairDisplay-SemiBold.ttf`
- `PlayfairDisplay-Bold.ttf`

**Download:** [Google Fonts - Playfair Display](https://fonts.google.com/specimen/Playfair+Display)

## Como Baixar

1. Acesse os links acima do Google Fonts
2. Selecione os pesos (weights) necessários:
   - Regular (400)
   - Medium (500)
   - SemiBold (600)
   - Bold (700)
3. Baixe os arquivos .ttf
4. Renomeie os arquivos conforme os nomes listados acima
5. Coloque todos os arquivos neste diretório (`assets/fonts/`)

## Nota

O app está configurado para carregar essas fontes automaticamente no `app/_layout.tsx`. Após adicionar os arquivos, reinicie o app.
